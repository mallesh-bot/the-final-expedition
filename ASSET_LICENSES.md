# Asset Licenses

Every asset in this build is original and generated by project code. No third-party art, audio or ripped game content is used.

| Asset | Source | License |
|---|---|---|
| Characters `public/assets/models/temp/ines_temp.glb`, `toby_temp.glb` (**TEMPORARY**) | Generated by `scripts/gen-temp-character.mjs` (skinned mesh, 17 bones, 19 procedural clips) | Project-owned |
| All textures (stone, cliff, masonry, moss, ground, bark, canvas, wood, rust, water, foliage atlas, glyphs, murals, stencils, particles) | Generated at runtime by `src/render/textures/ProceduralTextures.ts` | Project-owned |
| All geometry (terrain, rocks, vegetation, ruins, props, gorge city) | Generated at runtime (`src/world/*`, `src/chapters/ch1/*`) | Project-owned |
| All audio (ambience, footsteps, mechanisms, UI, adaptive music) | Synthesized with WebAudio (`src/audio/*`) | Project-owned |
| Three.js (runtime library, incl. DRACO/Basis decoders copied to `public/decoders`) | npm `three` | MIT |
| Fonts | System fonts only (Iowan Old Style / Palatino / Georgia; Avenir / Segoe UI) | Not bundled |

To replace the temporary characters, drop in new GLB files and update the `url` and `clips` map in `src/assets/characters.json`. No gameplay code needs to change.
